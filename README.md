GiftSlide für TikTok LIVE Studio

Online:
1. Neues öffentliches Repository auf github.com erstellen.
2. index.html, overlay.html und Ordner assets/ hochladen.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. GitHub-Pages-Adresse öffnen, Einstellungen auswählen und Overlay-Link kopieren.
5. In TikTok LIVE Studio als Link-/Browser-Quelle hinzufügen.

Eigene Bilder werden nur im jeweiligen Browser gespeichert. Für gemeinsame individuelle Bilder die fünf Dateien assets/1.webp bis assets/5.webp im Repository ersetzen.

Lokal: In diesem Ordner 'python -m http.server 8080' ausführen, dann http://localhost:8080 öffnen. localhost funktioniert nur auf dem eigenen PC.
